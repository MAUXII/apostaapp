# ApostaApp

Projeto de brincadeira entre amigos: monta a tabela de alavancagem, marca green/red no dia a dia e acompanha o streak do grupo.

Sem cadastro. Cria a salinha, manda o link no zap e pronto.

## Rodar local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Deploy

Sobe na [Vercel](https://vercel.com) conectando o repo. Build padrão Next.js, sem env vars.

> Por enquanto os dados ficam no navegador (localStorage). Cada um vê a salinha no device onde criou ou abriu o link.
